## Template Rules

- State reporting framework and donor basis before the figures.
- Separate restricted, unrestricted, and temporarily restricted resources.
- Tie every donor report line to project, activity, budget code, funding source, and evidence.
- Include budget, flexed budget where applicable, actual, variance, and action owner.
- Do not state Uganda PAYE, WHT, VAT, LST, NSSF, or filing values without source-register keys.
- Keep donor compliance caveats visible; do not bury them in notes.
