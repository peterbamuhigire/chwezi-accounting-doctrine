# Worked Example — Published Statement Review

> Fictional, test-labelled illustration; no issuer or client facts.

## Evidence layers

| Layer | Example |
|---|---|
| Extracted fact | The published note reports a defined revenue, lease liability and operating cash-flow amount for the stated period; each value needs a source locator. |
| Calculation | Analyst computes a clearly labelled cash-conversion ratio from those sourced amounts and records formula, units and comparative basis. |
| Inference | A movement may indicate working-capital pressure, but acquisition, currency, classification and timing explanations remain open. |
| Advice | Audit committee should ask for the cash-flow bridge and covenant headroom evidence; this is a question, not an assurance conclusion. |
| Disclosure risk | An MPM in public communication without a complete IFRS 18 reconciliation is logged as a review item, not treated as misstatement without further evidence. |
| Release | **Blocked** where source locators or reviewer route are missing. |
