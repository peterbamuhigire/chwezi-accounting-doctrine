|---|---|---|---|

| Operating profit subtotal | Recalculation from classified lines |  |  |

| Cash-flow interaction | IAS 7 classification and reconciliation to cash/cash equivalents |  |  |

## Release test

Release is blocked when a mandatory row is blank, evidence cannot be reconciled,
the reporting basis is unclear, or an IAS 1-only template is used for an IFRS
18 period without an approved transition caveat.
