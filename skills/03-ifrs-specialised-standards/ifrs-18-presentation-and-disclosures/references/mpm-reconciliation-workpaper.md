# Management-Defined Performance Measure Reconciliation

## MPM record

| Field | Entry |
|---|---|
| MPM name and exact label |  |
| Public communication locations | Annual report, investor presentation, press release, management commentary, website, other |
| Management purpose | Aspect of financial performance communicated and why management uses it |
| Calculation | Formula, components, period, sign convention and change from prior period |
| Most directly comparable IFRS-defined subtotal/total |  |
| Reconciliation | Each reconciling item with source accounts and explanation |
| Tax effect | Amount/method or not applicable with evidence |
| NCI effect | Amount/method or not applicable with evidence |
| Disclosure location | Single note and cross-references |
| Review state | Draft / pending / approved / blocked |

## Quality checks

- Label is not misleading or confusingly similar to an IFRS-defined subtotal.
- Calculation is consistent with the public communication and financial
  statements, unless a documented change is explained.
- Reconciliation starts from the most directly comparable IFRS subtotal/total.
- Reconciling items are traceable to the ledger, note or source evidence.
- Tax and NCI effects are identified where relevant.
- Changes in definition, composition or calculation are explained.
- Management, controller and IFRS reviewer routes are recorded.
