# Advanced IAS 36 CGU and VIU Workpaper

| Field | Required evidence |
|---|---|
| Basis / test date | Full IFRS or Section 27, reporting date and mandatory/indicator trigger |
| Asset population | Asset register, exclusions and carrying amounts |
| CGU definition | Independent cash inflows, monitoring, aggregation and goodwill allocation |
| Carrying amount | Assets and relevant liabilities on a comparable basis; no double count |
| FVLCD | Market-participant inputs, valuation technique, hierarchy and disposal costs |
| VIU | Current-condition cash flows, forecast period, terminal value, growth, rate and tax consistency |
| Recoverable amount | Higher of FVLCD and VIU, headroom and loss allocation |
| Sensitivity | Reasonably possible changes, tipping points and model limitations |
| Reversal | Trigger, cap, no-goodwill-reversal test and subsequent depreciation |
| Disclosure | CGU, goodwill, assumptions, sensitivity, loss/reversal and estimation uncertainty |
| Review state | Preparer, valuation reviewer, IFRS reviewer, exceptions and approval |
