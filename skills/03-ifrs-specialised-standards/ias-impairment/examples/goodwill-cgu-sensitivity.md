# Worked Example — Goodwill CGU Sensitivity

> Fictional, test-labelled illustration; no client facts.

## Review outcome

| Check | Result |
|---|---|
| Framework | TestCo Group selects full IFRS. |
| Annual test | Goodwill is assigned to the documented benefiting CGU and annual testing is triggered. |
| Recoverable amount | VIU and fair value less costs of disposal are independently considered. |
| Sensitivity | Growth, margin, cash conversion and discount-rate sensitivities are required; unsupported assumptions remain open. |
| Reversal | Proposed goodwill reversal is **blocked**. |
| Final release | Pending valuation and IFRS reviewer sign-off. |
