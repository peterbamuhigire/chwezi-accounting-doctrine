# Worked Example — Variable Consideration and Contract Modification

> Fictional, test-labelled illustration; no client facts.

| Review | Result |
|---|---|
| Variable consideration | Expected-value estimate is constrained using current evidence; update required at reporting date. |
| Modification | Added service is assessed for distinctness and stand-alone selling price before selecting modification treatment. |
| Contract balance | Revenue, contract asset, receivable and contract liability remain separate. |
| Principal/agent | Control evidence is required before gross/net presentation. |
