# Advanced IFRS 15 Judgement Matrix

| Area | Question | Evidence / result |
|---|---|---|
| Contract | Are rights, payment terms, enforceability and collectability present? |  |
| Combination | Should contracts entered together be combined? |  |
| Performance obligations | Which promises are distinct or a series? |  |
| Variable consideration | Expected value or most-likely amount; constraint and update |  |
| Financing | Is a significant financing component present? |  |
| Allocation | Relative stand-alone selling prices and estimation method |  |
| Timing | Point in time or over time; control and progress measure |  |
| Modification | Separate contract, prospective or cumulative catch-up treatment |  |
| Principal/agent | Control before transfer and gross/net conclusion |  |
| Returns/warranties | Refund liability, return asset, assurance/service warranty |  |
| Contract costs | Obtain/fulfil asset or expense; amortisation and impairment |  |
| Disclosure | Disaggregation, balances, obligations, judgements and remaining obligations |  |
