# Advanced IFRS 16 Lessee Workpaper

| Field | Required evidence |
|---|---|
| Contract / identified asset | Contract ID, asset specification, substitution rights, control of use |
| Commencement and term | Commencement, enforceable period, options, purchase option and reassessment triggers |
| Payments | Fixed, index/rate-linked, in-substance fixed, variable, incentives, prepayments and restoration |
| Exemptions | Short-term/low-value assessment and documented election |
| Discount rate | Implicit or incremental borrowing rate, currency, term, collateral, source and reviewer |
| Initial measurement | Liability PV and ROU components with calculation version |
| Subsequent schedule | Interest, payments, depreciation, impairment, FX if relevant, current/non-current split |
| Modification | Added/removed rights, revised consideration, separate lease test, remeasurement and posting map |
| Sale-and-leaseback | Transfer assessment and seller-lessee conclusion |
| Disclosure | Carrying amount, additions, expense, maturity, cash flows, judgements and exceptions |

## Reconciliation

`Opening liability + additions + interest - payments +/- remeasurements = closing liability`  
`Opening ROU + additions + depreciation - impairment +/- remeasurements = closing ROU`
