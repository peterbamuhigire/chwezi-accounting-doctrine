# Conceptual Framework Decision Tree

Use this record with the licensed Standard text and the source-verification
manifest. It is a reasoning aid, not a substitute for a Standard.

## Decision record

| Field | Required entry |
|---|---|
| Reporting basis and period | `<Full IFRS / IFRS for SMEs>; <period>` |
| Transaction and reporting entity | `<facts, parties, rights, obligations>` |
| Primary users and decision | `<investors/lenders/other creditors; decision>` |
| Standards searched | `<Standard, Interpretation, agenda decision, scope exception>` |
| Direct Standard applies? | `yes / no / uncertain` with source IDs |
| Permitted policy choice? | `yes / no / uncertain`; list only permitted alternatives |
| Element analysis | `asset / liability / equity / income / expense / none / uncertain` |
| Recognition analysis | `recognise / do not recognise / disclose / uncertain`; explain relevance and faithful representation |
| Derecognition analysis | `derecognise / retain / modify / uncertain`; identify transferred rights/obligations |
| Measurement basis | `historical cost / current value / other basis permitted by Standard`; explain relevance, faithful representation and cost constraint |
| Presentation and disclosure | `line item, aggregation/disaggregation, policy, judgement, uncertainty and risk effects` |
| Materiality | `quantitative indicators + qualitative factors + affected users` |
| Conclusion | `decision, rationale, rejected alternatives, impact and caveat` |
| Reviewer route | `preparer, reviewer role, approval state, date` |

## Ordering rule

1. Applicable Standard and scope first.
2. Framework concepts only for gaps, interpretation, or permitted policy choice.
3. Local policy and management judgement after the technical analysis.
4. Materiality and disclosure after recognition/measurement, while considering
   material information throughout.
5. Reviewer evidence before release.
