# Worked Example — No-Specific-Standard Policy

> Test-labelled illustration only. Not a client conclusion.

## Scenario

An entity identifies a transaction with an unusual digital-rights arrangement.
The fact pattern, contract, counterparty rights, timing, consideration and
termination clauses are recorded in a source pack. The preparer does not assume
that an unfamiliar label means that no Standard applies.

## Route

1. Search the relevant IFRS Standards, Interpretations, agenda decisions and
   scope exceptions; record the search and source IDs.
2. If the search shows a directly applicable Standard, stop the Framework route
   and apply that Standard.
3. If no Standard directly applies, complete the Framework decision tree:
   identify the element, assess recognition and derecognition, select the most
   relevant faithful measurement basis, and design transparent presentation and
   disclosure.
4. Document alternatives, user information needs, materiality, uncertainty,
   ledger/reporting impact, and reviewer route.

## Evidence outcome

| Result | State |
|---|---|
| Search record | Required |
| Framework memo | Required if no Standard directly applies |
| Policy approval | Pending named IFRS reviewer |
| Client release | Blocked until evidence and review are complete |
