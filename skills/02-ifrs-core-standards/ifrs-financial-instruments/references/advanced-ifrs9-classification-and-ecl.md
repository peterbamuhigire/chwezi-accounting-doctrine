# Advanced IFRS 9 Classification and ECL Workpaper

| Field | Required evidence |
|---|---|
| Basis / period / instrument | Full IFRS or Sections 11/12, reporting date, identifier and contract |
| Business model | Portfolio objective, management information, performance assessment, sales history and escalation |
| SPPI | Contractual cash-flow analysis and conclusion for principal, time value, credit risk and other lending risks/costs |
| Classification | Amortised cost, FVOCI or FVTPL; election and source |
| Effective interest / fair value | Schedule or valuation, inputs, hierarchy, transaction costs and exceptions |
| ECL scope | General or simplified approach, staging, exposure, PD, LGD, EAD, life, scenarios and forward-looking data |
| Collateral and guarantees | Value, enforceability, timing and recovery assumptions |
| Modification / derecognition | Cash-flow comparison, substantial-change assessment and linked record |
| Hedge accounting | Objective, item, instrument, risk, ratio, effectiveness, ineffectiveness and rebalancing |
| IFRS 7 disclosures | Significance, credit/liquidity/market risk, maturity and sensitivity tie-out |
| Review state | Preparer, model reviewer, IFRS reviewer, date, exceptions and release state |

## Guardrails

Do not hardcode loss rates, discount rates or market data. Preserve source data,
model versions, assumptions, sensitivity and correction history. A complete
calculation without source lineage is not release evidence.
