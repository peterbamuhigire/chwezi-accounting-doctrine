# Consolidated Statements Review Matrix

| Area | Required evidence | Result / exception |
|---|---|---|
| Basis and period | Framework, reporting date, currency, policies, alignment |  |
| Control | Power, relevant activities, variable returns, ability to affect returns, agency/structured entity |  |
| Investment entity | Definition, purpose, exit strategy, fair-value consequence and disclosures |  |
| Joint control | Contractual unanimous consent and relevant activities |  |
| JO/JV classification | Rights to assets/obligations versus rights to net assets |  |
| Associate | Significant influence and IAS 28 inputs |  |
| Local TB quality | Close state, currency, policy, source and sign-off |  |
| Consolidation mechanics | Like items, policy alignment, investment/equity elimination |  |
| Intercompany | AR/AP, sales, inventory profit, loans, interest, fees, dividends, cash flows |  |
| NCI | Initial and subsequent movements, ownership changes and presentation |  |
| FX/foreign operation | Rate evidence, translation and CTA treatment |  |
| IFRS 18 presentation | Categories, subtotals, MPMs and comparatives |  |
| IFRS 12 disclosures | Nature, risks, effects, restrictions, commitments, summarised information |  |
| IFRS 7 linkage | Credit, liquidity and market-risk disclosures |  |
| Tie-outs | Group TB, statements, notes, cash flows and retained earnings |  |
| Release | Open blockers, reviewer route and approval state |  |
